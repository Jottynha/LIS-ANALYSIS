# Samples de dados

Esta pasta contem insumos opcionais para referencia manual e testes exploratorios:

- `ACP/`: exemplos de arquivos ATP/ACP.
- `Listas ATP/`: listas `.lis` de referencia.

Observacoes:

- Esses arquivos nao sao necessarios para toda execucao em producao.
- Quando o volume aumentar, prefira mover os samples para um repositorio dedicado e manter aqui apenas o conjunto minimo necessario para validar fluxo e testes.
